# Thiranex Internship - Task 2

## Advanced CSS3 & Responsive Architecture

This project is an upgraded version of my Task 1 portfolio,
developed using modern CSS3 techniques and responsive design principles.

## Features

- CSS Grid for complex page layouts.
- Flexbox for component alignment.
- Mobile-first responsive architecture.
- CSS custom properties and variables.
- Functional dark and light theme.
- Responsive mobile navigation.
- CSS transitions and hover effects.
- Modern gradients and backdrop blur.
- Accessible navigation and keyboard focus styles.
- Reduced-motion accessibility support.
